Egyptian Arabic / Arabizi support note
The Arabic knowledge files include direct Q&A examples for common Egyptian Arabic and Arabizi questions, especially about the Pyramids of Giza and Khufu. Example user phrases supported by the knowledge base include: "مين بنا الهرم؟", "meen bana el haram?", "emta etbana khufu?", "اتعمل من ايه؟", and "ليه الأثر ده مهم؟".
